## FAQ

### What is XCutors?

XCutors is a collection package for Windows that bundles several popular Roblox executors (Volt, Synapse Z, Potassium, Wave) and a universal loader (xcutorsLoader) into one easy-to-manage download.

### Is XCutors safe to use?

The files included are provided for educational and personal customization purposes. You should always run any executable in a controlled environment and understand the potential risks of using third-party tools with online games.

### How do I update the executors?

Check the official GitHub repository's Releases page regularly. Download the latest package and replace your existing files to ensure compatibility with Roblox updates.

### Which executor is the best?

The 'best' executor depends on your specific needs and the scripts you plan to run. XCutors bundles several options so you can test and choose the one that works best for your use case.

### My anticomponent flagged a file. What should I do?

Some security software may flag tools like these due to their nature. It's a common occurrence. You may need to add an exception for the XCutors folder or use the tools in a virtual machine if you are concerned.

### Does this work on Mac or Linux?

No. XCutors is designed specifically for Windows desktop environments. The bundled executors and loader are Windows executables.

### Can I add my own executor to the loader?

The 'xcutorsLoader' is designed to work with the specific set of bundled executors. Adding external or new executors is not currently supported to ensure stability and safety.
